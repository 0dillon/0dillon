# Featured Projects

A curated collection of open-source projects, smart contracts, and tools built on Stellar and Soroban.

## Smart Contracts & Web3
- **[Accensa Contracts](https://github.com/accensa/accensa-contracts):** Secure on-chain receipt anchoring and merchant refund vaults for x402 payments on Stellar.
- **[HaloPay Yield Contracts](https://github.com/HaloPaye/halopay-yield-contracts):** Automated yield optimization and vault strategies for decentralized finance.
- **[Stellar Agent Guard](https://github.com/0dillon/stellar-agent-guard-sdk):** Autonomous agent guardrails, pre-flight simulation, and execution security for Soroban transactions.
- **[RemitLend](https://github.com/0dillon/remitlend):** Cross-border remittance and micro-lending protocol on Stellar.

## Developer Tooling & Diagnostics
- **[Protocol-Canary](https://github.com/0dillon/Protocol-Canary):** Protocol compatibility checks for Stellar XDR, Soroban RPC endpoints, and smart contract ledger state.
- **[Soroban State Lens](https://github.com/0dillon/Soroban-state-lens):** State inspection and contract storage explorer for Soroban contracts.

## AI & Accessibility
- **[Aidee](https://github.com/0dillon/Aidee):** Voice-first accessibility tools empowering visually impaired individuals to access digital work opportunities without reliance on visual displays.
